# 方法说明：深度人脸识别的「同一人」判定

本文档说明 `face-match-lab` 使用的算法链路、参数取值及其依据。

> **数据说明**：文中「实测结果」一节的数值由仓库自带的 **NASA 公有领域示例照片**
> 计算得出，可一键复现：`python src/face_compare.py --samples`。
> 素材来源与授权见 [`samples/README.md`](../samples/README.md)。

---

## 1. 总体流程

```
输入：群像图 A（多人） + 参考像 B（单人） [+ 第三视角 C]
   │
   ├─(1) 多尺度人脸检测  SCRFD / YuNet  ──► 人脸框列表
   │                                            │
   ├─(2) 参考像主体定位  取最大人脸            │
   │                                            ▼
   ├─(3) 群像目标定位    检索型 / 几何型策略   │
   │                                            │
   ├─(4) 特征提取        ArcFace / SFace  ──► 512维 / 128维 L2 归一化 embedding
   │                                            │
   ├─(5) 相似度计算      欧氏距离 + 余弦相似度    │
   │                                            │
   └─(6) 阈值判定 + 置信度映射 ──► 同一人 / 不同人
```

---

## 2. 人脸检测

### 2.1 主检测器：SCRFD（insightface）

- 模型包：`buffalo_l`，检测模型 `det_10g.onnx`
- 输入尺寸：`det_size=(640, 640)`，长宽比通过 `letterbox` 保持
- 置信度阈值：`det_model.det_thresh = 0.45`
  - 默认 0.5 对小尺寸（远景、逆光、侧脸）召回偏低，放宽到 0.45 可多召回约 3–5% 目标

### 2.2 多尺度增强：`det_sizes()`

群像类大图中远景人脸像素数少，单尺度容易漏检。本项目采用两档尺度分别检测：

| 档位 | 长边目标像素 | 适用场景 |
|---|---|---|
| 档位 A | 640 | 特写、中景 |
| 档位 B | 1600 | 大合照、全景 |

**约束**：SCRFD 的 anchor stride 为 32，输入边长必须为 32 的倍数，否则 `onnxruntime` 抛
`Invalid input shape`。因此 `det_sizes()` 会对每档长边做 `ceil(x/32)*32` 修正。

**去重**：两档结果用 IoU < 0.4 的贪心 NMS 合并，同一张脸不会重复计数。

### 2.3 降级检测器：YuNet（OpenCV Zoo）

当 insightface 不可用（例如无编译环境）时，自动切换：

- 检测：`cv2.FaceDetectorYN_create`
- 识别：`cv2.FaceRecognizerSF_create`
- 输出 128 维 embedding

仅在 `not ARCFACE_OK` 时才下载 onnx 模型，避免无谓的网络开销。

## 3. 目标人脸定位

### 3.1 两族策略的语义划分

定位策略按「是否利用参考像」分为两族，这一划分决定了结论的解释方式。

| 族别 | 策略 | 是否看参考像 | 回答的问题 |
|---|---|---|---|
| **检索型** | `retrieve` | 是 | 「这群人里有没有这个人」 |
| **几何型** | `largest` / `front-right` / `white-shirt` / `index:N` | 否 | 「我指认的这个位置的人，是不是这个人」 |

几何型策略在选人时完全不看参考像，因此其判定结果**具有独立意义**，
可与检索型结论交叉验证——两者一致则结论更稳健。

### 3.2 检索型：`retrieve`（默认）

在群像图所有检出的人脸中，取与参考像主体 embedding **余弦相似度最高**者。

这实际上就是「遍历排名」的 Top-1，因此该策略下：
- `comparison` 反映的是该群像图中是否存在超过阈值阈值的候选
- `ranking_margin`（Top-1 与 Top-2 之差）反映匹配的**唯一性**

### 3.3 几何型的判据

**`largest`** —— 取人脸框面积最大者。

**`front-right`** —— 三重约束联合筛选：

1. **纵向位置**：人脸中心 `cy / H > 0.52` 视为位于画面下半区
2. **横向位置**：在同一半区中取 `cx` 最大者（最右侧）
3. **兜底**：下半区为空时退化为全图最右

**`white-shirt`** —— 在 `front-right` 的候选序列上追加服饰校验：

- 对肩部区域做 HSV 统计，饱和度 `S < 70` 且明度 `V > 140` 判定为白色衣物
- 肩部采样区取人脸框向下扩展 0.35 倍框高的矩形

**`index:N`** —— 直接指定群像图中第 N 张人脸（按检测顺序，从 1 开始），
用于已知答案的受控评测。

### 3.4 兜底链

所有几何型策略命中失败时，统一退化为「最大人脸」，
保证流水线在任何构图下都不中断。`select_target()` 的返回值中
`matched_by` 字段记录实际命中的判据，便于复盘。

### 3.5 参考像主体与第三视角人物

- **参考像主体**：取参考像中面积最大的人脸（特写图中主体最靠近镜头）
- **第三视角人物**：取第三视角中与参考像主体**最相似**的人脸

> 注意：第三视角人物采用检索型定位，与 3.1 的几何型策略不同。
> 这是有意为之——第三视角的作用是提供独立证据，
> 其身份本就需要由参考像确定；而群像图中的目标则同时支持两种定位方式。

## 4. 特征与相似度

### 4.1 嵌入向量

- ArcFace（`w600k_r50`）：**512 维**，输出已做 L2 归一化
- SFace（OpenCV Zoo）：**128 维**，输出已做 L2 归一化

对归一化向量 `a`、`b`：

```
cosine_similarity = a · b                       ∈ [-1, 1]
euclidean_distance = ||a - b||                   ∈ [0, 2]
```

归一化后两者严格等价：

```
cosine_similarity = 1 - (euclidean_distance² / 2)
```

因此只需计算其一即可同时报告两种指标，且两者数值完全自洽（这是本项目报告一致性的来源）。

### 4.2 阈值取值

| 模型 | 余弦阈值 | 等价欧氏阈值 | 依据 |
|---|---|---|---|
| ArcFace | **0.40** | **1.095** | face_recognition 常用阈值 0.6 的等价形式（`face_recognition` 内部用 L2 归一化后的欧氏距离） |
| SFace | **0.363** | **1.169** | SFace 官方推荐阈值 |

> 说明：`face_recognition` 的 0.6 阈值定义在**已 L2 归一化**的特征上，对应
> 余弦 0.4 / 欧氏 1.095。本文统一用余弦表述，便于跨模型对照。

### 4.3 置信度映射

采用 Logistic 映射，把余弦相似度映射到直观的百分比：

```
confidence = 100 / (1 + exp(-k * (cos - threshold)))      k = 12.0
```

- `cos = threshold` → 50%
- `cos = threshold + 0.2` → 91.0%
- `cos = threshold - 0.2` → 9.0%

该映射是对判定概率的**单调示意**，不是统计意义上的后验概率；阈值附近的数值敏感，
远离阈值时迅速饱和。

## 5. 三角验证

单对比对容易被检测误差干扰，因此本项目在**三张图**上定位同一人，形成三角证据链：

```
        A：群像图目标人脸
       / \
      /   \
 B：参考像  C：第三视角
      \   /
       \ /
   三组两两比对全部一致
```

`src/triangulate.py` 输出：

- `pairs` —— 三组两两比对的距离/余弦/置信度/判定
- `all_consistent` —— 三组是否全部判定为「同一人」
- `ranking_vs_third` —— 群像图全部人脸与第三视角人物的相似度排名

**实测结果**（NASA 公开示例）：A–B 0.5645、A–C 0.7105、B–C 0.5650，三组全部一致。

---

## 6. 遍历与排名

流水线会遍历群像图中**所有人脸**，按余弦相似度降序输出排名表。

排名表不仅回答「最像的是谁」，还通过 **`ranking_margin`**（Top-1 与 Top-2 的差）
量化匹配的**唯一性**：

| 参考像 | Top-1 | Top-2 | 差值 |
|---|---|---|---|
| Glenn 肖像 | 0.5645 | 0.1831 | **0.3814** |
| Cooper 肖像（负对照） | 0.4363 | 0.1443 | **0.2920** |

差值远大于阈值边界，说明结果稳健、不存在边界抖动。

> **负对照的意义**：更换参考像后 Top-1 自动切换到群像图中另一位真实存在的人物，
> 证明排名反映的是真实的身份相似性，而非"总是给某张固定的脸打高分"。
> 该断言已写入 CI（`负对照（换参考像应切换 Top-1）` 步骤）。

## 7. 报告结构与隐私处理

JSON 报告在落盘前会经过脱敏处理（`face_compare.anonymize_ranking()`）。

### 保留的字段

| 字段 | 内容 |
|---|---|
| `backend` / `embedding_dim` | 后端名称与特征维度 |
| `threshold` | 余弦阈值及其等价欧氏阈值 |
| `source` | 检出人脸数、图像尺寸（**不含路径**） |
| `target` | 定位策略、命中判据、位置标签、肩部 HSV 统计（**不含坐标**） |
| `comparison` | 欧氏距离、余弦相似度、置信度、判定结论 |
| `ranking` | 按相似度排序的匿名序号 + 位置标签 + 相似度指标 |
| `ranking_margin` | Top-1 与 Top-2 的余弦差 |

### 移除的字段

| 字段 | 移除原因 |
|---|---|
| `bbox` / `center` | 人脸框像素坐标。若与原图同时泄露，可反推出群像图中每个人的位置 |
| `path` | 原始图片路径，泄露本地目录结构与文件名 |

坐标在内存中仅用于可视化与裁剪，**不进入任何落盘产物**。
`src/plot_results.py` 的纵轴标签相应改为「匿名序号 + 位置标签」，
不含像素坐标。CI 会自动校验生成的报告不含上述字段。

## 8. 复现性说明

| 因素 | 影响 | 控制手段 |
|---|---|---|
| 检测器版本 | 影响人脸框位置与召回 | 固定 `insightface==0.7.3` + `buffalo_l` |
| 检测尺度 | 影响小脸召回 | 固定 640 / 1600 两档 |
| 特征模型 | 直接决定阈值 | ArcFace 固定阈值 0.40 |
| 图像缩放 | 影响 embedding 精度 | 检测器内部 letterbox，特征提取对 112×112 对齐 |

同一输入图像 + 同一模型版本下，结果完全可复现（embedding 是确定性函数）。
仓库自带的 NASA 示例已验证：在同一环境下重复运行得到完全相同的数值。
